# 受伤警报与化学呼救:钙波、玉米与寄生蜂

23 篇讲了触碰。这一篇讲更严重的刺激:被虫子咬。植物被咬之后要做两件事:一是把警报传到身体其他部位,让还没被咬的叶子提前备战;二是向外界释放气味,把吃虫子的天敌招过来。这两件事都有很漂亮的实验,也都很容易被说成"植物会痛""植物会求救"。

> 一句话先记住:**被咬的叶片会在几秒内产生钙信号,并在两分钟内沿维管束传到远处叶片,触发信号的是谷氨酸,接收信号的是类谷氨酸受体通道;被咬的玉米会释放特定气味,招来寄生蜂和寄生线虫。这些都是警报和防御机制,不代表植物能感觉到痛,也不代表它在有意识地"呼救"。**

---

## 一、警报怎么传遍全身

### 1.1 早期线索:受伤会产生电信号

人们很早就知道,番茄叶片被咬或被烫伤后,远处的叶片也会开始合成防御蛋白,比如抑制昆虫消化酶的蛋白酶抑制剂。问题是:信号是怎么传过去的?

Wildon 等 (1992, *Nature*) 在番茄里记录到,受伤会产生沿植株传播的电信号,和远处叶片的防御反应有关。Mousavi 等 (2013, *Nature*) 进一步发现,拟南芥的这种叶片间电信号依赖一类叫**类谷氨酸受体**(GLR)的基因,缺了它们,远处叶片的防御反应就会减弱。

### 1.2 亲眼看到警报在传播

Toyota 等 (2018, *Science*,Gilroy 实验室) 给拟南芥装上了一种遇到钙离子就发绿色荧光的蛋白探针,然后让毛毛虫去咬,或者用剪刀剪伤叶片。在显微镜下可以看到:

```text
被咬后 2 秒内      → 伤口处的荧光亮起(细胞内钙离子浓度升高)
约 2 分钟内        → 荧光沿着叶脉和茎的维管束传到其他叶片
传播速度           → 约每秒 1 毫米,比单纯靠扩散快得多
再过几分钟         → 远处叶片里的防御激素茉莉酸明显上升
```

### 1.3 谷氨酸是开关

研究者给叶片滴加不同的氨基酸,只有谷氨酸能引发这种远距离的钙信号。把 GLR3.3 和 GLR3.6 两个类谷氨酸受体基因同时突变后,远距离钙信号就消失了。合理的解释是:细胞受伤后,谷氨酸漏到细胞外,激活附近的 GLR 通道,钙离子涌入,信号由此启动并沿维管束传开。

### 1.4 植物没有神经,却用了相似的分子

在动物大脑里,谷氨酸是最主要的兴奋性神经递质,谷氨酸受体是神经元之间快速传递信号的核心部件。植物没有神经元,却用了同一类分子来传递受伤警报。《科学》同期的评论文章用"类似神经系统的信号"来形容这项发现。

但"相似的分子"不等于"相似的系统":

| | 动物神经系统 | 植物受伤信号 |
| --- | --- | --- |
| 传递信号的结构 | 神经元和突触 | 维管束和普通细胞 |
| 速度 | 每秒可达数十米 | 约每秒 1 毫米 |
| 用途 | 感觉、运动、思考 | 让远处叶片提前启动防御 |
| 有没有痛觉 | 有专门的痛觉通路和脑 | 没有证据 |

所以这是一套警报机制,而不是痛觉。

## 二、玉米叶片的"呼救"

### 2.1 被咬才释放的气味

Turlings、Tumlinson 与 Lewis (1990, *Science*) 研究了玉米幼苗被毛虫啃咬后的反应:

- 被毛虫啃过的玉米会释放大量萜类挥发物
- 只用刀割伤叶片,释放量很少;但如果在伤口上涂上毛虫的口腔分泌物,释放量就上来了
- 没受伤的叶片,涂不涂口腔分泌物,都检测不到这些萜类

也就是说,玉米能分辨"被虫咬"和"被割伤",线索在毛虫的唾液里。后来研究者从毛虫口腔分泌物中鉴定出了触发这一反应的化合物(Alborn 等,1997,*Science*),命名为 volicitin。

### 2.2 寄生蜂学会了这种气味

一种寄生蜂(*Cotesia marginiventris*)会把卵产在毛虫体内,幼蜂孵出后吃掉毛虫。实验发现,雌蜂把这种气味和寄主毛虫联系起来之后,就会循着气味找到被咬的玉米,进而找到毛虫。效果上,相当于玉米请来了"保镖"。

### 2.3 "呼救"是比喻

作者在同一篇论文里就指出:这些萜类可能本来是用于直接防御的,吸引天敌只是附带的作用。同一研究团队后来在 1995 年的综述中也认为,植物被咬后合成这些化合物,不太可能只是为了招来寄生蜂和捕食者。寄生蜂能利用它,是寄生蜂学会了"偷听"。

## 三、玉米根的"呼救",以及它是怎么丢的

### 3.1 地下也有同样的机制

Rasmann 等 (2005, *Nature*) 研究了玉米根。玉米根萤叶甲(*Diabrotica virgifera virgifera*)的幼虫是北美和欧洲玉米的重要害虫,专门在地下啃根。研究发现:

- 根被幼虫啃咬后,会释放一种叫 **(E)-β-石竹烯** 的挥发物
- 这种物质能吸引一类专门寄生昆虫的线虫(昆虫病原线虫),线虫钻进幼虫体内把它杀死
- 田间试验中,会释放这种物质的玉米品种,周围的幼虫被线虫感染的比例约高 5 倍
- 给不释放的品种的根周围人工加入这种物质,成虫羽化数量减少到一半以下

### 3.2 北美品种丢了这个能力

研究者检测了不同来源的玉米:欧洲品种和玉米的野生祖先大刍草,根被啃咬后都会释放 β-石竹烯;而大多数北美品种不会。作者推测,北美玉米在育种过程中丢失了这个能力。这是根据分布格局做出的推断,不是直接验证过的结论。

### 3.3 能不能装回去

后续研究(Degenhardt 等,2009,*PNAS*)把一个能合成 β-石竹烯的基因转进不释放的玉米品种,田间试验中根受到的损害减轻了。这说明"恢复呼救信号"在原理上可以作为一种生物防治手段。

这个例子提醒我们:育种通常只盯着产量、抗倒伏等少数目标,一些看不见的防御性状可能就在这个过程中悄悄丢掉了。

## 常见误区

1. **"植物被咬会痛"**:植物会产生快速的钙信号和电信号,但没有痛觉通路,也没有证据表明它有感受
2. **"植物有神经"**:植物用了和动物神经相似的分子(谷氨酸、类谷氨酸受体),但信号走的是维管束和普通细胞,没有神经元
3. **"植物会主动呼救"**:挥发物可能本来是防御物质,吸引天敌是附带作用;是寄生蜂和线虫学会了利用它
4. **"受伤就会释放这些气味"**:玉米能分辨机械损伤和虫咬,虫子口腔分泌物里的成分才是关键触发信号
5. **"育种只会让作物越来越好"**:北美玉米很可能在育种中丢失了根部招引线虫的能力,育种目标之外的性状容易被忽视
