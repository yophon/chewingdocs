# Rubisco 与光呼吸:一个 30 亿年前留下的缺陷

01 篇说过,C4 植物多花能量给 Rubisco 装了一个"CO2 泵"。这一篇先看这个泵要解决的问题:光合作用最核心的酶 Rubisco 为什么又慢又会出错,它出错之后植物要付出什么代价,以及为什么这个代价在高温下特别大。后面讲到的 C4、CAM、藻类的浓缩机制和人类的改造尝试,本质上都是在给这一个酶打补丁。

> 一句话先记住:**Rubisco 诞生在大气几乎没有氧气的远古时代,分不太清 CO2 和 O2。错抓 O2 会产生有毒的副产物,植物必须花能量把它回收,还要放掉一部分已经固定的碳,这就是光呼吸。温度越高、越干旱,错抓得越多,C3 植物的损失就越大。**

---

## 一、Rubisco 是什么

### 1.1 卡尔文循环的入口

Rubisco 的全称是"核酮糖-1,5-二磷酸羧化酶/加氧酶"。它负责光合作用里把无机碳变成有机物的第一步:

```text
羧化反应(想要的):
  核酮糖-1,5-二磷酸(5 碳) + CO2  ->  2 个 3-磷酸甘油酸(3 碳)
```

生成的 3-磷酸甘油酸进入卡尔文循环,一部分变成糖,一部分重新生成核酮糖-1,5-二磷酸,继续接收下一个 CO2。地球上生物圈固定的碳,绝大部分都要经过这一步。

### 1.2 又慢又多

和大多数酶相比,Rubisco 慢得出奇:每个分子每秒只能完成几次羧化反应,而很多常见的酶每秒能催化成千上万次。

植物的应对办法很朴素:**多造**。Rubisco 可以占到叶片可溶性蛋白的一半左右,因此成了地球上含量最多的蛋白质。Ellis 在 1979 年就用"世界上最丰富的蛋白质"来形容它;Bar-On 与 Milo (2019) 又对它的全球总量和平均催化速率做了估算。

造这么多酶要消耗大量的氮,这也是后面 C4 植物"省氮"的来源:Rubisco 周围的 CO2 浓度一高,同样的光合速率就不需要那么多 Rubisco。

### 1.3 还会错抓 O2

Rubisco 的名字里有"加氧酶"三个字,因为它也能让 O2 代替 CO2 参加反应:

```text
加氧反应(不想要的):
  核酮糖-1,5-二磷酸 + O2  ->  1 个 3-磷酸甘油酸 + 1 个 2-磷酸乙醇酸(2 碳)
```

2-磷酸乙醇酸不仅没用,还会抑制卡尔文循环里的酶,必须尽快清除。

## 二、光呼吸:回收错误产物的代价

### 2.1 一条跨三个细胞器的回收路线

清除 2-磷酸乙醇酸的过程叫**光呼吸**。它要依次经过叶绿体、过氧化物酶体和线粒体:

```text
叶绿体:      2-磷酸乙醇酸 -> 乙醇酸
过氧化物酶体: 乙醇酸 -> 乙醛酸 -> 甘氨酸
线粒体:      2 个甘氨酸 -> 1 个丝氨酸 + CO2 + NH3
过氧化物酶体: 丝氨酸 -> 甘油酸
叶绿体:      甘油酸 + ATP -> 3-磷酸甘油酸,回到卡尔文循环
             NH3 要重新固定,再耗 ATP 和还原力
```

算一下碳:两个 2-磷酸乙醇酸共 4 个碳,最后只有 3 个碳以甘油酸的形式回收,**1 个碳以 CO2 的形式放掉了**。整个过程还要额外消耗 ATP 和还原力。所以光呼吸同时造成两种损失:丢碳,费能。

"光呼吸"这个名字来自它的表现:只在光下发生,消耗 O2、放出 CO2,看起来像呼吸。它和线粒体里分解糖获取能量的细胞呼吸是两回事。

### 2.2 为什么不能干脆不回收

既然光呼吸这么亏,能不能关掉它?实验给出了否定答案。Somerville 与 Ogren 在 1979 年筛到了拟南芥的光呼吸缺陷突变体:这些植物在高 CO2 的环境里长得正常,一放到普通空气中就生长不良。原因很简单:只要 Rubisco 还会错抓 O2,2-磷酸乙醇酸就会产生,不清除就会堆积中毒。

所以光呼吸不是"缺陷",而是对 Rubisco 缺陷的必要补救。人类改造光呼吸的思路(见 08 篇)也不是删掉它,而是给它换一条更省的路线。

### 2.3 损失有多大:一组实测数字

Ehleringer 与 Björkman (1977) 测量了多种 C3 和 C4 植物的光量子效率,也就是每吸收一份光能能固定多少 CO2。在 30°C 时:

| | 普通空气(21% O2) | 低氧(2% O2) |
| --- | ---: | ---: |
| C3 植物 | 约 0.052 | 约 0.073 |
| C4 植物 | 约 0.053 | 约 0.054 |

单位:每吸收 1 摩尔光量子固定的 CO2 摩尔数。

把 O2 降到 2%,光呼吸基本被压住,C3 的效率提高了约四成;换句话说,30°C 的普通空气里,光呼吸让 C3 少固定了约三成的碳。C4 植物有 CO2 泵,O2 浓度变化对它几乎没有影响。同一项研究还发现,C3 的光量子效率随温度升高而下降,C4 的则基本不随温度变化。

## 三、为什么高温下更严重

### 3.1 CO2 和 O2 的比例在变

光呼吸的强弱取决于 Rubisco 周围 CO2 和 O2 的相对浓度。温度升高时:

- **溶解度**:CO2 在水里的溶解度比 O2 下降得更快,叶绿体里 CO2 相对 O2 的比例变低
- **酶本身**:Rubisco 区分 CO2 和 O2 的能力也随温度升高而变差

两个因素叠加,温度越高,错抓 O2 的比例越大。

### 3.2 干旱和强光火上浇油

- **干旱**:植物为了少丢水会关小气孔,外面的 CO2 进不来,叶片内部的 CO2 被用掉后得不到补充,而光合作用本身还在不断放出 O2
- **强光**:光反应提供的能量充足时,限制光合速率的就变成了 CO2 供应,光呼吸占的比例更显眼

所以**高温、干旱、强光**是 C3 植物最吃亏的组合,也恰好是 C4 和 CAM 植物最占优势的环境(见 04、05 篇)。

## 四、为什么演化没有修好它

### 4.1 生在没有氧气的年代

一般认为,Rubisco 起源于 30 亿年前前后。那时大气中几乎没有氧气,CO2 却很多,"会错抓 O2"根本不构成问题。约 24 亿年前,蓝藻释放的氧气在大气中积累起来,即"大氧化事件",这个缺陷才暴露出来。此后氧气越来越多、CO2 越来越少,问题也越来越严重。

### 4.2 "准"和"快"不能兼得

既然有二十多亿年时间,为什么没演化出一个不会出错的 Rubisco?Tcherkez、Farquhar 与 Andrews (2006, *PNAS*) 比较了多种生物的 Rubisco,发现一个规律:**区分 CO2 和 O2 越准的 Rubisco,催化速度往往越慢**。他们的解释是,两种反应的化学过程太相似,酶要提高辨别力,就得把反应中间态抓得更紧,而抓得越紧,产物释放得越慢。

由此,作者认为每种生物的 Rubisco 可能已经在"准"和"快"之间调到了适合自身环境的最佳点:CO2 充足的环境里可以要快,CO2 稀缺的环境里只能要准。

### 4.3 红藻的例子

一些生活在温泉里的红藻,比如 *Galdieria partita*,拥有已知区分能力最强的 Rubisco:按 Uemura 等 (1997) 的测定,它的特异性因子约为 238,是高等植物 Rubisco 的 2.4–2.5 倍。

把这种 Rubisco 搬进作物,似乎就能直接减少光呼吸。Whitney 等 (2001) 真的这样试过:把红藻 *Galdieria sulphuraria* 和一种硅藻的 Rubisco 基因装进烟草的叶绿体基因组。结果外来的蛋白虽然大量合成,却**没有正确折叠和组装**,基本都成了不溶的沉淀,还挤占了烟草自己的 Rubisco,导致叶片固定 CO2 的能力和植株生长都下降了。Rubisco 的组装需要一整套配套的分子伴侣,不是换一个基因那么简单。按我们查到的资料,让红藻 Rubisco 在作物叶绿体里正常工作至今仍未实现。

## 五、几种"补丁"

既然酶本身很难改,演化给出的办法基本都是**改变 Rubisco 周围的环境**,让它少碰到 O2:

| 补丁 | 做法 | 详见 |
| --- | --- | --- |
| C4 | 两种细胞分工,把 CO2 泵进维管束鞘 | 03、04 |
| CAM | 夜里存 CO2,白天关着气孔放出来 | 05 |
| 单细胞 C4、C2 等变体 | 在一个细胞里分区,或回收光呼吸放出的 CO2 | 06 |
| 蓝藻和藻类 | 用蛋白质外壳包住 Rubisco,再主动泵入无机碳 | 07 |
| 人工改造 | 光呼吸旁路、C4 水稻、移植羧酶体等 | 08 |

唯一试图"改酶本身"的路线,就是上面的红藻 Rubisco 移植,目前也还没走通。

## 常见误区

1. **"光呼吸就是植物在呼吸"**:光呼吸是回收 Rubisco 错误产物的代谢路线,和线粒体里分解糖获取能量的细胞呼吸是两回事
2. **"光呼吸纯属浪费,去掉就好"**:去掉光呼吸,有毒的 2-磷酸乙醇酸会堆积,缺陷突变体在普通空气里长不好;能改的只是回收路线
3. **"Rubisco 是个设计失败的酶"**:它在"准"和"快"之间受化学原理限制,很可能已接近各自环境下的最优;地球上的有机碳几乎都靠它固定
4. **"温度升高只会让酶反应更快,对光合作用有利"**:温度升高同时改变了 CO2 与 O2 的比例,C3 植物的光呼吸会明显加重
5. **"C4 植物没有 Rubisco"**:C4 植物照样用 Rubisco 和卡尔文循环,只是把它们集中在 CO2 浓度很高的维管束鞘细胞里
