# 根的感官与"植物神经生物学"之争

前面几篇讲的感官大多发生在地上:光、触碰、受伤、气味、声音。这一篇转到地下,讲根怎么感知重力和水分、能不能分辨"自己""亲戚"和"陌生人"。最后回到贯穿第五层的那个问题:植物有这么多感知能力,能不能说它有"神经"、有"意识"?

> 一句话先记住:**根冠细胞里装满淀粉的"平衡石"沉向细胞底部,告诉根哪边是下;根还能感知水分梯度,向水生长;有实验报道植物能分辨亲缘关系,但证据仍有争议。植物的感知和反应确实复杂,靠的是电信号、钙信号和化学信号,但这不等于有神经、有感受或有意识,这也是多数植物学家反对"植物神经生物学"这个提法的原因。**

---

## 一、根怎么知道哪边是下

### 1.1 平衡石假说

1900 年,Haberlandt 和 Němec 各自独立提出了**淀粉-平衡石假说**:

- 根尖最前端有一个帽子状的结构叫**根冠**,根冠中央的细胞里有一些装满淀粉的颗粒(淀粉体)
- 淀粉比细胞质重,无论根怎么摆放,这些颗粒总是沉到细胞朝下的那一侧
- 细胞根据颗粒沉降的方向判断重力方向,就像人内耳里的耳石帮助判断头的朝向

支持这个假说的证据有:切掉根冠,根就不再向下弯曲;不能合成淀粉的拟南芥突变体仍能感知重力,但敏感度明显降低。所以淀粉体是感知重力的重要部件,但可能不是唯一的机制。

### 1.2 从感知到弯曲

感知到重力之后,根冠把生长素更多地运到根的下侧。在根里,较高浓度的生长素会抑制细胞伸长,于是下侧长得慢、上侧长得快,根就向下弯曲。这和 21 篇讲的向光弯曲是同一类机制,只是方向和器官不同。

### 1.3 达尔文的"根脑"

达尔文在 1880 年的《植物的运动力》末尾写道:根尖能感知多种刺激并指挥相邻部分的运动,作用就像低等动物的大脑。这句话后来常被"植物神经生物学"的支持者引用。达尔文用的是比喻,他描述的是根尖作为感知和调控中心的功能。

---

## 二、根怎么找水

根除了向下长,还会朝着更湿润的方向弯曲,这叫**向水性**。

自然条件下,向水性常常被向重力性掩盖,不容易观察。Kobayashi 等 (2007, *PNAS*) 在拟南芥中找到了一个向水性必需的基因,命名为 *MIZ1*(日语"水"与"屈性"):

- *miz1* 突变体的根失去了向水性,但向重力性和伸长生长都正常,说明两种向性走的是不同的通路
- *MIZ1* 主要在根冠的中央细胞里表达,也就是感知重力的那批细胞所在的位置

同一个根冠,既感知重力,也参与感知水分,这说明根尖确实是一个集中处理多种信号的部位。

## 三、根能认出"自己"和"亲戚"吗

### 3.1 区分自己和别人

Gruntman 与 Novoplansky (2004, *PNAS*) 用一种多年生草本做实验,发现同一株植物的根彼此相遇时,会减少在对方区域的生长;而遇到其他个体的根,则没有这种回避。更有意思的是,把同一株植物切成两半分开培养一段时间后,两半的根也逐渐不再互相回避。作者认为,这种"自我识别"依赖的是生理上的协调,而不是基因上的身份。

### 3.2 区分亲戚和陌生人

Dudley 与 File (2007, *Biology Letters*) 用美洲海凯菜(*Cakile edentula*,一种五大湖沿岸的一年生植物)做实验:

- 每盆种 4 株,要么全是同一株母本的后代(兄弟姐妹),要么全来自不同母本(陌生个体)
- 和陌生个体种在一起时,植株把更多资源分配给了根;和兄弟姐妹种在一起时则没有这种增加

根多意味着地下竞争更激烈。作者认为,这符合亲缘选择理论:和亲戚少竞争,对共有的基因更有利。他们推测根与根的接触可能是识别的线索,但具体机制至今不清楚。

### 3.3 争议

同期就有学者(Klemens,2008,*Biology Letters*)提出质疑:原文的结论依赖于统计模型里"亲缘"和"植株大小"之间的交互作用,在这种情况下直接比较两组的平均值并不可靠;作者也没有展示足够的原始数据让读者自行判断。Dudley 与 File 随后发文回应,双方各执一词。植物亲缘识别目前仍是一个有实验报道、但证据有争议的方向。

## 四、"植物神经生物学"之争

### 4.1 这个提法从哪来

2006 年,Brenner 等人在 *Trends in Plant Science* 上发表文章,提出"植物神经生物学"这一领域,主张用研究神经系统的视角研究植物的信号传递。前面几篇讲到的很多研究,比如捕蝇草的动作电位、受伤后的谷氨酸钙波、含羞草的"习惯化",都被纳入这个框架。

### 4.2 反对的声音

2007 年,36 位植物学家联名在同一期刊上发表短文《植物神经生物学:没有脑,哪来的收获?》(Alpi 等,2007),批评这个提法。核心意见是:植物没有神经元、突触和脑,借用神经生物学的术语只会造成误解,无助于理解植物信号本身的机制。

2019 年,Taiz 等人在 *Trends in Plant Science* 上发文,标题就是《植物既没有、也不需要意识》。他们的主要论点是:

- 动物的意识依赖于在演化中形成的、结构和功能都极其复杂的脑
- 按照神经科学中关于意识所需结构的标准,目前只有脊椎动物、节肢动物和头足类动物可能满足
- 植物没有神经元,更没有脑,把植物的复杂反应说成"意识"缺乏依据
- 一些被用来支持植物"学习"的实验,设计本身也存在问题

也有人反驳,认为与其争论定义,不如多做实验。争论还在继续,但目前主流植物学界并不接受"植物有意识"的说法。

### 4.3 比较稳妥的理解

| 能确定的 | 不能确定或缺乏证据的 |
| --- | --- |
| 植物能感知光、触碰、受伤、气味、振动、重力和水分 | 植物有感受、痛觉或意识 |
| 植物有电信号、钙信号和化学信号,能在全身传递 | 植物有神经系统 |
| 植物的反应能区分不同刺激,有些变化能保留一段时间 | 植物的"习惯化"等同于动物的学习和记忆 |
| 植物之间能通过挥发物感知彼此的受伤信号 | 森林里的树通过地下网络有意分享资源、照顾后代 |

## 五、回到起点

这个系列从"C4 为什么没有淘汰 C3"开始,一路讲到植物怎么处理光、感知光、感知光以外的世界。贯穿始终的是同一条线:

- C4 用多耗的能量换来高温强光下的高效率,在凉爽阴暗的地方就不划算
- 孔雀秋海棠的光子晶体在弱光下多吸收绿光,在强光下反而表现更差
- 捕蝇草要数到两次才合上夹子,用一点延迟换来更少的误报
- 根向下长、向水长,但遇到亲戚是否少长根,还要看证据

**植物的每一种"本事",都是在某种环境里用一种成本换一种优势。** 理解一种植物,就是理解它在什么环境里、为什么值得付出这样的代价。

---

## 常见误区

1. **"根是植物的大脑"**:达尔文用的是比喻;根尖是感知和调控的中心,但没有神经元和脑
2. **"根只会向下长"**:根同时感知重力、水分等多种信号,向水性在自然条件下常被向重力性掩盖
3. **"植物被证明能认亲"**:有实验报道,但统计方法和解释都受到质疑,机制也不清楚
4. **"有电信号就有神经"**:植物的电信号和钙信号在普通细胞和维管束中传递,不经过神经元
5. **"植物有意识"**:主流植物学界不接受这个说法,目前也没有证据支持
