# 光敏色素:种子开关与邻居探测

第三层讲的是光怎么被叶片吸收、反射和散射。从这一篇开始的第四层换一个角度:植物不只把光当能量,还把光当信息来读。它要知道的事情很多:头顶有没有别的叶子、现在是一年中的什么时候、光从哪个方向来。第一个要认识的受体是光敏色素,它读的是红光和远红光的比例。

> 一句话先记住:**光敏色素能在"吸收红光"和"吸收远红光"两种状态之间来回切换,读的是环境里红光与远红光的比例。叶片吸收红光、放过远红光,所以这个比例一下降,植物就知道附近有别的叶子:种子会推迟发芽,幼苗会抢先长高。**

---

## 一、莴苣种子的开关

### 1.1 Borthwick 等的实验

20 世纪 50 年代初,美国农业部的 Borthwick、Hendricks 等人研究一种叫"大急流"(Grand Rapids)的莴苣品种。这种种子吸水后需要见光才发芽。他们用不同波长的光照射,发现(1952 年发表于 *PNAS*):

```text
照一下红光(约 660 nm)       -> 发芽
照一下远红光(约 730 nm)     -> 不发芽
红 -> 远红                  -> 不发芽
红 -> 远红 -> 红            -> 发芽
红 -> 远红 -> 红 -> 远红    -> 不发芽
```

不管交替照多少次,结果**只取决于最后一次照的是哪种光**。这说明种子里有一种色素,能在两种状态之间可逆切换。

### 1.2 找到这种色素

1959 年,Butler 等人在芜菁子叶等材料里,用分光光度计测到了一种色素:照红光后它的吸收谱变成一个样子,照远红光后又变回来,变化正好和种子实验预测的一致(同年发表于 *PNAS*)。他们给它取名"光敏色素"(phytochrome),意思是"植物的色素"。

## 二、两种状态

### 2.1 Pr 和 Pfr

```text
Pr(吸收红光的形态)  --红光-->  Pfr(吸收远红光的形态)
Pfr                  --远红光-->  Pr
Pfr                  --在黑暗中缓慢-->  Pr
```

- **Pfr 是"开"的状态**:它会进入细胞核,调控一大批基因,启动发芽、去黄化等反应
- **Pr 是"关"的状态**
- 自然光里红光和远红光都有,细胞里的光敏色素总是一部分在 Pr、一部分在 Pfr,两者的比例反映了环境中红光与远红光的比例

### 2.2 一个家族

光敏色素不是一个蛋白,而是一个家族。拟南芥有 5 种(phyA 到 phyE),分工不同。其中 phyB 是感知红光与远红光比例、引发避荫反应的主力。

### 2.3 为什么这个比例能说明问题

17 篇讲过,叶片强烈吸收红光,却大量反射和透过远红光。所以:

```text
开阔地上的阳光:红光与远红光差不多
经过一层叶片后:红光被吃掉,远红光大多穿过来
在别的植物旁边:邻居叶片反射过来的远红光增多
```

**红光与远红光的比例,是一个关于"附近有没有别的植物"的可靠信号**。光的总量会随天气、时刻变化,这个比例却主要由周围的叶片决定。

## 三、种子什么时候发芽

### 3.1 等一个空隙

很多小粒种子(包括大量杂草种子)需要光才能发芽。它们的种子储备很少,如果在别的植物底下发芽,幼苗很快就会因为缺光饿死。

光敏色素让它们能"判断":照到的光里远红光偏多,说明头顶被叶片盖住了,暂时不发芽;等到上面的树倒了、草被割了、土被翻了,照进来的光红光比例升高,再发芽。这就是为什么土壤里能积累大量休眠的杂草种子,一翻地就冒出一片。

### 3.2 夜间耕地

既然很多杂草种子是被翻地时的那一下光照"唤醒"的,那么在黑夜里耕地,种子翻到地表时见不到光,是不是就不发芽了?

德国 Erlangen 大学的 Hartmann 和 Nezadal (1990) 提出并试验了这种"夜间耕作"的思路。后来各地的田间试验结果不一:有的报告白天翻耕后的杂草出苗明显多于夜间翻耕,有的只减少了一小部分,还有的认为减少得不够多,不足以单独作为除草手段。比较一致的看法是:它能减少一部分对光敏感的杂草,但需要和其他除草方法配合。

## 四、察觉邻居

### 4.1 Ballaré 等的实验

Ballaré、Scopel 和 Sánchez (1990) 用两种植物(一种曼陀罗属植物 *Datura ferox* 和白芥 *Sinapis alba*)的幼苗做了实验:

- 把一株幼苗移进一群同样大小的幼苗中间,**3 天之内**它的茎就开始加速伸长,而这时邻居的叶片还远没有真正挡住它的光
- 用滤光材料把茎罩起来,挡住周围幼苗散射过来的远红光,这种加速伸长就减弱甚至消失了

这说明植物察觉竞争的第一个信号不是"光变少了",而是"远红光变多了"。它在被真正遮住之前,就已经开始应对。

### 4.2 避荫反应

察觉到邻居后,植物会启动一整套反应,叫避荫反应:

- 茎和叶柄加速伸长,抢先长高
- 叶片角度变得更直立
- 分枝(禾本科是分蘖)减少,把资源集中到主茎
- 提前开花,在被完全遮住之前尽快结籽

### 4.3 代价

抢着长高不是免费的:

- 茎秆变细,更容易倒伏
- **防御变弱**:Moreno 等 (2009) 发现,拟南芥处在远红光偏多的环境里,对茉莉酸(主要的抗虫防御激素,见 24 篇)的敏感性明显下降。作者用不能启动伸长反应的突变体排除了"资源都拿去长高了"的解释,认为这是植物根据竞争风险主动调低防御投入

农业上种植过密时,作物长得细高、分蘖少、容易倒伏、病虫害加重,部分原因就是避荫反应。减弱作物的避荫反应,让它密植时不再白白徒长,是育种研究的方向之一。

## 常见误区

1. **"植物只是被动接受光"**:植物通过光敏色素等受体主动读取光里的信息,并据此改变发芽、生长和开花
2. **"种子见光就发芽"**:决定性的是红光与远红光的比例;照到远红光偏多的光反而会抑制很多种子发芽
3. **"植物被遮住了才开始长高"**:Ballaré 等的实验显示,植物在被真正遮住之前,靠邻居反射过来的远红光就开始抢先伸长
4. **"长得越高越有竞争力"**:避荫反应有代价,茎秆变弱、防御下降,种得太密反而减产
5. **"夜间耕地能代替除草剂"**:田间试验结果不一,一般只能减少一部分杂草,需要和其他方法配合
