# "印钞机"的真相:宽松与量化宽松

新闻和网上常说"印钞机启动""开闸放水"。前三篇讲了钱从哪里来:纸币只是换形态,新钱主要来自贷款,人民银行调节的是银行的底钱。这一篇把"印钞"这个比喻拆开,看它在中国和在美日欧分别指什么。

> 一句话先记住:**在中国,"印钞机启动"基本等于让银行更容易、更便宜地放贷,但放宽不等于放出去。美日欧还会让央行直接买资产(量化宽松),新钱可以绕过贷款进入市场。两种情况下,钞票本身印不印都不是关键**。

---

## 一、"印钞"在中国指什么

通常是这几件事:

- **降准**:银行能拿去放贷的钱变多
- **降息**:借钱成本变低,企业和个人更愿意借
- **人民银行给银行投放资金**:逆回购、MLF、再贷款等
- **政策引导**:鼓励银行多给小微企业、制造业放贷,放松买房贷款的限制

它们起作用的链条:

```text
降准、降息、投放资金
  → 银行可贷资金多了、成本低了
  → 企业和居民借款
  → 贷款创造存款,M2 增加
  → 钱流向消费和投资
```

链条的关键一环在中间:**有没有人来借**。

---

## 二、放宽不等于放出去

人民银行能让银行有钱可贷,但**不能逼人来借**。

- 企业觉得生意难做,不想扩产
- 居民觉得房价、收入前景不明朗,不想买房

这时就算利率很低,贷款也放不出去,钱只在银行体系里打转,进不了市场。这种情况有个说法叫"**牵马到河边,马不喝水**"。日本长期面临这个问题,中国近几年也有"信贷需求不足"的讨论。

怎么从数据上看出"推不动":

```text
银行体系资金充裕:短期市场利率很低,央行持续净投放
但是:
  贷款增量偏弱,尤其是企业和居民的中长期贷款
  M1 增速明显低于 M2(钱躺在定期账户里)
→ 闸开了,水没流出去
```

这些数据怎么读,见下一篇。

## 三、量化宽松:央行直接买资产

量化宽松(QE)是美联储、日本央行、欧洲央行在 2008 年金融危机后大规模使用的做法:**央行在市场上大量买国债等资产,用新创造的准备金付款**。

如果卖方是养老基金、保险公司这类非银行机构,钱直接到了卖方手里:

```text
美联储从养老基金手里买入 100 亿美元国债
  养老基金:国债 -100 亿,银行存款 +100 亿    (存款直接增加)
  养老基金的开户银行:存款 +100 亿,准备金 +100 亿
  美联储:资产 +100 亿国债,负债 +100 亿准备金
```

不用等谁来贷款,存款就增加了。这就是 QE 比放宽贷款"更像印钞"的原因。

反过来,央行卖出资产,或者到期的债券不再续买,叫"**缩表**",是在回收货币。

### 3.1 2020 年的美国

2020 年疫情期间:

- 美国政府大量发债,其中一部分用来给居民直接发钱(纾困支票)
- 美联储同时在市场上大量买入国债

政府发债发钱,央行在市场上买债,两件事叠加,是最接近"印钞撒钱"的做法。之后几年美国通胀明显上升,和这个有关。

---

## 四、中国和美国的区别

| | 中国 | 美国 |
| --- | --- | --- |
| 新钱主要渠道 | 银行贷款 | 银行贷款 + 央行买资产 |
| 央行买国债 | 二级市场买卖,规模有限 | 量化宽松时大规模购买 |
| 央行和财政的边界 | 法律禁止财政透支、禁止直接认购国债 | 美联储同样只在二级市场买,但规模巨大 |
| 新闻里的说法 | 降准降息、结构性工具 | QE、缩表 |

一句话:**中国新增货币仍然主要靠银行贷款**;美日欧除了贷款,还有央行直接买资产这条路。

---

## 五、坎蒂隆效应:谁先拿到新钱

新钱不是平均分到每个人手里的。**谁先拿到新钱,谁就先得益**:

```text
先拿到的:
  拿到贷款的企业、政府项目、金融市场
  → 用新钱买东西、买资产时,价格还没涨

后拿到的:
  工资要过一段时间才跟着涨
  → 拿到钱时,物价和资产价格可能已经涨了
```

经济学里把这叫"**坎蒂隆效应**",名字来自 18 世纪的经济学家理查德·坎蒂隆。这也是为什么有人说"放水"会推高资产价格,拉大贫富差距。

## 六、货币政策与财政政策

"放水"不只是人民银行的事,政府花钱也是一条渠道:

| | 货币政策 | 财政政策 |
| --- | --- | --- |
| 谁来做 | 人民银行 | 政府(财政部等) |
| 手段 | 降准降息、给银行投放资金 | 发国债、减税、补贴、搞基建 |
| 特点 | 间接,要靠银行放贷传导 | 直接,政府自己花钱 |
| 推不动时 | 利率再低也没人借 | 不依赖借款需求,但要考虑政府债务 |

借款需求不足、货币政策"推不动"的时候,往往要靠财政政策直接花钱来带动,比如以旧换新补贴、发特别国债。政府发债,银行买债,钱花出去后变成企业和居民的存款(10 篇)。两者配合,就是新闻里常说的"财政货币协同发力"。

## 常见误区

1. **"印钞就是印钞厂加班"**:印钞只是存款换成现金,"印钞机"是放宽贷款或央行买资产的比喻
2. **"降息一定能刺激经济"**:借款需求不足时,效果有限
3. **"QE 就是直接给老百姓发钱"**:QE 是央行买资产;直接发钱是财政行为。2020 年美国是两者叠加
4. **"放水只会推高物价"**:新钱也可能主要推高资产价格,或者停在银行体系里
5. **"中国也在搞大规模 QE"**:人民银行二级市场买卖国债的规模和美国 QE 差很远,新钱主要仍靠贷款
