# 数电票:开票信息与核对查验

03 篇讲了该要哪种票。这一篇讲票本身:现在的发票长什么样、开票时要给对方什么信息、拿到票核对哪些地方、怎么查真伪。

> 一句话先记住:**数电票不用盖章、没有纸质原件,开票只需要公司全称和纳税人识别号。拿到票重点核对购买方信息、项目名称和金额,真伪在全国增值税发票查验平台查**。

---

## 一、什么是数电票

数电票全称"全面数字化的电子发票",2024 年 12 月 1 日起在全国推广,基本取代了纸质发票和过去的税控电子发票。

| 特征 | 数电票 | 过去的纸质发票 |
| --- | --- | --- |
| 形态 | 电子文件 | 纸质 |
| 盖章 | 不需要发票专用章 | 要盖发票专用章 |
| 号码 | 20 位发票号码 | 发票代码 + 发票号码 |
| 文件格式 | XML、PDF、OFD | — |
| 开票方式 | 在电子发票服务平台开具,不需要税控设备 | 要用税控盘等专用设备 |
| 交付方式 | 自动进入受票方的税务数字账户,也可以发邮箱、扫码下载 | 邮寄或当面交付 |

票面抬头写着"电子发票(增值税专用发票)"或"电子发票(普通发票)"。另外还有几种特定形式,比如"电子发票(铁路电子客票)""电子发票(航空运输电子客票行程单)"。

### 1.1 税务数字账户

开给公司的数电票,会自动归集到公司在电子发票服务平台上的**税务数字账户**。财务能在里面查询、下载每一张开给公司的票,也在这里做勾选抵扣。

所以发票文件丢了可以重新下载,不会因为丢票而作废。但报销时仍要按公司流程提交,因为财务需要把每张票和具体的业务、报销单对应起来。

### 1.2 打印件和重复报销

- 电子发票和纸质发票具有同等法律效力,电子文件本身就是发票,打印件只是一种展示形式
- 同一张电子发票可以打印很多份,所以**公司按发票号码查重,同一张票只能报销一次**
- 财政部、国家档案局允许符合条件的电子发票以电子形式报销入账归档,不必再打印纸质件。公司是否已经支持,看公司的报销制度

## 二、开票时要给对方什么

| 项目 | 是否必填 | 说明 |
| --- | --- | --- |
| 购买方名称 | 必填 | 公司全称,一个字都不能错 |
| 纳税人识别号 | 必填 | 即统一社会信用代码 |
| 地址、电话 | 选填 | |
| 开户行及账号 | 选填 | |
| 接收邮箱或手机号 | 视情况 | 方便对方把发票文件发给你 |

几点说明:

- **专票和普票要的信息一样**。2017 年 7 月 1 日起,购买方是企业的,索取普票也要提供纳税人识别号,只写名称不合规,财务可能退回
- 向财务要一份公司的标准开票信息,存在手机里,开票时直接复制发给对方,避免对方手输出错
- 个人消费开票时,抬头写个人姓名即可,这种票不能拿来报公司的账;出差打车、住宿这类公务支出,抬头要写公司

## 三、拿到票核对什么

| 位置 | 核对什么 | 不对怎么办 |
| --- | --- | --- |
| 购买方名称、纳税人识别号 | 和公司开票信息逐字一致 | 让对方红冲后重开(见 07 篇) |
| 项目名称 | 和实际买的商品或服务一致 | 不一致要重开 |
| 数量、单价(货物) | 和合同、订单一致 | 不一致要重开 |
| 金额、税率、税额、价税合计 | 和实际付款一致,税率和业务匹配 | 金额错了要重开 |
| 开票日期 | 和业务发生时间对得上 | 跨年的票要提醒财务(见 08 篇) |
| 特定业务信息 | 建筑、运输、不动产租赁等业务要求填写的项目地点、起运地等 | 交给财务判断 |
| 销售方名称 | 和合同签约方、收款方一致 | 不一致有风险(见 08 篇) |

### 3.1 项目名称前面的星号

项目名称常写成 `*信息技术服务*软件开发服务` 这样。两个星号中间是"商品和服务税收分类"的简称,由开票系统按编码自动生成,不用对方手填。

它的用处是:**看分类和实际业务是否匹配**。买的是软件服务,分类却是 `*餐饮服务*`,这张票就有问题。

### 3.2 金额和价税合计

票面上的"金额"是不含税金额,"价税合计"才是实际付的钱。核对付款时看价税合计,两者的换算见 05 篇。

## 四、怎么查真伪

查验入口是国家税务总局的**全国增值税发票查验平台**(<https://inv-veri.chinatax.gov.cn>),按页面提示输入发票号码、开票日期、金额等信息即可。

查验能告诉你:

- 这张票是不是税务系统里真实开具的
- 票面信息和系统记录是否一致
- 发票当前的状态,比如是否已经被红冲

查验不能告诉你:**这笔业务是不是真实的**。票是真的,但项目、金额和实际业务不符,照样不合规。

## 常见误区

1. **"没盖章的发票是假的"**——数电票不需要盖发票专用章
2. **"电子发票要打印出来才有效"**——电子文件本身就是发票,打印件只是展示形式
3. **"公司要普票,只写名称就行"**——购买方是企业的,普票也要写纳税人识别号
4. **"查验通过就说明没问题"**——查验只证明票是真开的,业务是否真实、票面是否一致,还要自己核对
5. **"发票文件删了就找不回来"**——开给公司的票都在税务数字账户里,可以重新下载
