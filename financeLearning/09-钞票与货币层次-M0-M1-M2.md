# 钞票与货币层次:M0、M1、M2

第一层讲的是发票和增值税。从这一篇开始,换到另一个问题:新增的钞票是怎么进入市场的?回答之前要先分清两个词:"钞票"和"钱"。日常说的"印钞票",和经济统计里的"货币",其实不是一回事。

> 一句话先记住:**钞票只是钱的一小部分,大部分钱是银行账户里的存款数字。M0 是银行体系之外的现金,M1 再加上随时能付款的活期存款,M2 再加上定期和储蓄存款**。

---

## 一、钞票不等于钱

你手里的现金、钱包里的纸币,只占全部货币的很小一部分。在中国,现金不到 M2 的 5%。

大部分钱是**银行账户里的存款数字**:

- 你的工资卡余额
- 公司对公账户里的余额
- 定期存款、大额存单

所以问"新钱怎么进入市场",主要是在问:**这些存款数字是怎么多出来的**。这是下一篇的内容,这一篇先把"钱分几层"讲清楚。

---

## 二、货币分三层

按"用起来方不方便"(经济学叫流动性)分层:

| 层次 | 包括什么 | 特点 |
| --- | --- | --- |
| **M0** | 流通中的现金(含数字人民币) | 随时能花 |
| **M1** | M0 + 单位活期存款 + 个人活期存款 + 非银行支付机构客户备付金 | 随时能付款 |
| **M2** | M1 + 单位定期存款、个人定期存款等(统称"准货币") | 一般说的"货币总量",超过 300 万亿元 |

层层包含的关系:

```text
M0 = 流通中的现金(含数字人民币)
M1 = M0 + 单位活期存款 + 个人活期存款 + 非银行支付机构客户备付金
M2 = M1 + 单位定期存款 + 个人定期存款 + 其他存款等
```

### 2.1 为什么要分层

不同层次的钱,对经济的意义不同:

- **M0、M1** 是"随时能花的钱",它多了,说明大家手头活跃,在消费、在投资
- **M2** 里多出来的那部分是"暂时不花的钱",它多了,可能只是大家把钱存起来了

所以看货币数据不能只看总量,还要看钱停在哪一层。13 篇会讲 M1 和 M2 增速差怎么读。

### 2.2 口径会调整

M1 现在的口径是人民银行 **2025 年起**调整的。旧口径的 M1 不含个人活期存款,也不含微信、支付宝背后的备付金。手机支付普及以后,大量日常付款的钱就"漏"在 M1 之外,旧 M1 越来越不能反映真实的活跃程度。

调整后,跨年份比较 M1 要注意口径是否一致,以人民银行公布的口径说明为准。

---

## 三、M0:流通中的现金

### 3.1 判断关键:在不在银行外面

"流通中的现金"就是大家手里实实在在的纸币和硬币,包括:

- 你钱包里的钱
- 商店收银台里的零钱
- 公司保险柜里的备用金
- 家里压箱底的现金

不算 M0 的现金:

- **印钞厂刚印好、还在人民银行发行库里的钞票**:还没发出来
- **银行金库里、ATM 里的现金**:这是银行自己的库存,不在公众手上

### 3.2 一个例子:ATM 取现

你卡里有 1000 元存款,去 ATM 取了 1000 元现金:

```text
取钱前:
  1000 元是你的活期存款 → 算在 M1 里,不算 M0
  ATM 里的现金是银行库存 → 不算 M0

取钱后:
  现金到了你手上 → M0 增加 1000 元
  你的存款减少 1000 元 → M1 里的存款部分减少 1000 元

M1、M2 总量不变,只是"存款"变成了"现金"
```

你把钱存回去,M0 又会减少。

### 3.3 容易搞混的两点

- **微信、支付宝余额不是 M0**。它们是电子账户里的数字,不是现金。对应的资金是"客户备付金",按新口径算在 M1 里
- **数字人民币算 M0**。它是人民银行发行的、法律地位等同于现金的数字形式,2022 年底起计入 M0

所以 M0 可以简单理解为:**银行体系之外的钞票、硬币,加上数字人民币**。

## 四、现金和存款的本质区别

同样是"我的钱",背后欠你钱的人不一样:

| 形式 | 本质 | 安全性来源 |
| --- | --- | --- |
| 现金、数字人民币 | 人民银行直接发行的法定货币 | 国家信用 |
| 银行存款 | **银行欠你的钱** | 银行自身经营 + 存款保险 |
| 微信、支付宝余额 | 你在支付机构账户里的钱 | 对应资金(备付金)集中存放在人民银行 |

几个推论:

- **存款不是"放在银行保险柜里的钱"**,而是你借给银行的钱。银行出问题时,存款保险最多保障**每人在每家银行本金加利息 50 万元**
- 支付机构的余额相对安全,因为备付金不能被支付公司挪用,但它也不是现金本身
- 只有现金和数字人民币不依赖任何一家商业银行或支付公司

## 五、M0 的意义

### 5.1 日常分析不是重点

在中国,大家基本用手机支付,M0 只占 M2 的不到 5%。分析经济形势时,主要看 M1、M2 和社融,M0 不是重点。

但 M0 也不是完全没用。

### 5.2 信心指标

经济不确定、大家担心银行时,人们更愿意持有现金,因为现金是唯一不依赖银行的钱。M0 的变化能反映这种心理。

### 5.3 近年不降反升

按理说手机支付普及了,现金应该越用越少,但中国 M0 这几年一直在增长。原因有几种说法:

- 数字人民币也算进了 M0
- 一部分人出于"防备心理",在家里多存了现金
- 老年人、农村地区,还有一些小生意,仍然常用现金

所以 M0 的意义不在于"现在大家用多少现金",而在于**反映大家对未来的信心**。

### 5.4 季节性:春节取现

春节前大家集中取现发红包、置办年货,M0 会大幅增加。这会牵动银行体系的资金:

```text
居民集中取现
  → 银行要用自己存在人民银行的准备金,去换现金
  → 银行体系可用资金(准备金)减少,资金面紧张
  → 人民银行在春节前多投放资金,补上缺口
  → 节后现金存回银行,人民银行再把资金收回来
```

新闻里"春节前央行大额投放",很多时候就是这个原因。准备金和投放工具在 11 篇讲。

## 常见误区

1. **"印了多少钞票,就新增了多少钱"**:纸币大多是用存款换出来的,只是钱换了形态。新钱主要来自贷款,见下一篇
2. **"微信余额就是现金"**:不是 M0,按新口径算在 M1 里
3. **"手机支付普及了,M0 会一直下降"**:近年中国 M0 反而在增长
4. **"存款和现金一样安全"**:存款是银行的负债,存款保险有每人每家银行 50 万元的上限
5. **"M1 数据可以跨年直接比"**:2025 年起口径变了,比较时先确认口径
