# 红字发票

06 篇提到,一张票拖着不勾选,可能会遇到对方已经冲红的情况。"冲红"就是开红字发票。这一篇讲红字发票是什么、什么时候要开、买卖双方各要做什么,以及作为经手的员工,遇到冲红该怎么配合。

> 一句话先记住:**红字发票是金额为负数的发票,用来冲掉之前开的一张蓝字发票的全部或一部分。数电票不能作废,开错了只能红冲再重开;买方已经勾选或入账的,要走红字发票信息确认单,由双方确认**。

---

## 一、蓝字和红字

- **蓝字发票**:正常开具的发票,金额是正数
- **红字发票**:金额为负数的发票,必须对应一张已经开出的蓝字发票

红字发票相当于对原来那张票说:"这张不算了",或者"这张要少算一部分"。两张票加在一起,才是这笔交易最终的金额和税额。

几条基本规则:

- 红字发票必须**一一对应**原来的蓝字发票,不能凭空开
- 冲红的金额不能超过原蓝字发票的金额
- 可以**全额冲红**,也可以**部分冲红**

---

## 二、什么时候要开红字发票

| 场景 | 怎么冲 | 之后 |
| --- | --- | --- |
| 开错了:名称、税号、金额、税率等填错 | 全额冲红 | 重新开一张正确的蓝字发票 |
| 退款、退货、服务中止,整单退 | 全额冲红 | 不再重开 |
| 部分退款、销售折让(事后打折) | 按退的部分冲红 | 不再重开 |

### 2.1 例子:税号写错

你买服务付了 1060 元,对方开了一张蓝字发票(金额 1000、税额 60),后来发现公司税号写错了:

```text
1. 对方开一张 -1060 元的红字发票(金额 -1000、税额 -60),冲掉原来那张
2. 对方再开一张税号正确的 1060 元蓝字发票

结果:错票 + 红字发票 = 0,只剩下正确的那张
```

### 2.2 例子:部分退款

服务费 1060 元,后来对方退了 212 元:

```text
对方开一张 -212 元的红字发票(金额 -200、税额 -12)
蓝字 1060 + 红字 -212 = 实际交易 848 元(金额 800、税额 48)
```

### 2.3 为什么不能直接作废

纸质发票时代,当月开错的票可以作废,跨月才需要开红字。**数电票没有作废功能**,开具后发生开票有误、销售退回、服务中止、销售折让等情况,一律开红字发票。

---

## 三、要不要买方配合,看这张票用过没有

数电票的红字发票,按国家税务总局公告 2024 年第 11 号的规则,分两种情况:

### 3.1 买方还没有用途确认、也没有入账

```text
开票方填开《红字发票信息确认单》
  -> 直接全额开具红字发票
  -> 不需要买方确认
```

也就是说,只要你们公司还没勾选、还没入账,对方可以自己冲红,你们不需要做任何操作。

### 3.2 买方已经用途确认或入账

```text
开票方或受票方任一方,在电子发票服务平台填开《红字发票信息确认单》
  -> 另一方确认
  -> 开票方依据确认单开具红字发票
```

- **对方在规定时间内要确认**。实务中常见的口径是 72 小时内,超时未确认的确认单会作废,需要重新发起;具体以最新规定为准
- **已经抵扣过的,要做进项税额转出**:买方已经把这张票用于申报抵扣的,要按确认单上的税额,从当期进项税额里转出,也就是把之前少交的这部分税补回来

### 3.3 卖方那一侧

卖方开出红字发票后,对应的销项税额在开具当期冲减。所以冲红对双方的税都有影响,不是开票方一方的事。

---

## 四、员工该怎么做

经手采购、报销的员工,不需要自己操作税务系统,但要知道什么时候该通知财务:

| 你的情况 | 该怎么做 |
| --- | --- |
| 票还没交给财务 | 直接让对方冲红重开,把新票交上去 |
| 票已经交给财务、已经报销 | **先告诉财务**,别让对方直接冲红;财务可能要在系统里确认,报销单也可能要重新提交或调整 |
| 对方说要冲红,但你没提过要求 | 也要通知财务;可能是对方在退款,也可能是对方自己的账出了问题 |
| 发现票面有错 | 尽早提出;越早冲红,牵涉的环节越少 |

一个原则:**票已经进入公司流程,就不要私下和对方处理冲红**。确认单需要公司财务在系统里确认,已经抵扣的还要做转出,绕过财务只会让账对不上。

---

## 常见误区

1. **"红字发票就是作废发票"**——作废是让票失效,红冲是另开一张负数发票抵消;数电票只有红冲,没有作废。
2. **"冲红是卖方的事,和我们无关"**——买方已经勾选或入账的,要在系统里确认,已抵扣的还要做进项转出。
3. **"开错了让对方再开一张对的就行"**——必须先冲掉错票,否则同一笔交易会有两张有效发票。
4. **"部分退款只能整张冲掉重开"**——可以只冲退款的那部分。
5. **"对方发起的确认单,放着不管也没事"**——确认单有时限,超时作废,冲红就没完成,后续还要重新发起。
