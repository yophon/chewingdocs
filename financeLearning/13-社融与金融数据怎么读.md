# 社融与金融数据怎么读

前几篇讲的是机制:钱从哪里来、人民银行怎么调节、为什么放宽不等于放出去。这一篇讲怎么用每月公布的数据,判断新钱有没有真的流进市场、流到了哪里。

> 一句话先记住:**看新钱有没有进入实体经济,看社融;看钱是在流动还是躺着,看 M1 和 M2 的增速差。每月中旬的金融数据、20 日左右的 LPR、上旬的 CPI 和 PPI,是读懂货币形势的三个固定节点**。

---

## 一、社会融资规模是什么

"社会融资规模"(社融)统计**实体经济(企业和居民)从金融体系拿到了多少钱**。它比单看银行贷款更全:

| 构成 | 含义 |
| --- | --- |
| 人民币贷款 | 银行对企业和居民发放的贷款,通常是最大的一块 |
| 外币贷款 | 折合成人民币计算 |
| 委托贷款、信托贷款 | 通过银行或信托公司"代为放贷",常说的表外融资 |
| 未贴现银行承兑汇票 | 企业之间用银行承兑汇票支付形成的融资 |
| 企业债券 | 企业直接发债融资 |
| 政府债券 | 国债、地方政府债券,2018 年后逐步纳入社融统计 |
| 非金融企业境内股票融资 | 企业上市、增发融资 |
| 其他 | 资产支持证券、贷款核销等 |

### 1.1 增量和存量

- **社融增量**:当月或当年新增了多少。新闻说"社融增量 X 亿元",指的是这个
- **社融存量**:截至某时点的余额。看趋势常用"社融存量同比增速"

单月增量波动大,判断趋势时,存量增速更稳。

---

## 二、社融和 M2 的关系

两个指标从两头看同一件事:

```text
社融:看"借出去多少"   → 实体经济从金融体系借到的钱
M2:看"手里有多少"     → 企业和居民账户里的存款
```

两者大体同向,但不完全一致。例如政府发债:

```text
政府发行债券
  → 社融增加(政府债券计入社融)
  → 钱先进国库,财政存款不算 M2
  → 政府把钱花出去,变成企业、居民存款,M2 才增加
```

所以政府债券集中发行的月份,社融可能很高,M2 却没有同步变化。

### 2.1 结构比总量重要

同样的社融增量,含义可能完全不同:

- **政府债券撑起来的社融**:说明财政在发力,但企业和居民借款意愿不一定强
- **企业和居民贷款撑起来的社融**:说明市场主体愿意借钱,经济内生动力更强

---

## 三、M1 和 M2 增速差

回顾 09 篇:M1 是随时能付款的钱,M2 还包括定期存款。

- **M1 增长快**:钱都在活期账户里,企业和个人在花钱、投资,经济比较活跃
- **M1 增长慢、M2 增长快**:钱都存成了定期,大家不想花、不敢投,经济偏冷

新闻常说"M1 与 M2 剪刀差",指的是 M1 增速减去 M2 增速:

```text
剪刀差为正、扩大:资金活化,交易和投资活跃
剪刀差为负、扩大:存款定期化,资金活化程度低
```

两个注意:

- **2025 年起 M1 口径调整**,纳入了个人活期存款和支付机构备付金。跨年比较要用同口径数据,以人民银行的说明为准
- 再看存款结构:居民存款大增,可能说明储蓄倾向强;存款流向理财、股市,新闻叫"存款搬家"

---

## 四、贷款数据怎么看

金融数据里的"人民币贷款增加 X 亿元",要拆开看:

| 分项 | 大致对应 | 说明什么 |
| --- | --- | --- |
| 居民中长期贷款 | 主要是房贷 | 楼市冷热 |
| 居民短期贷款 | 消费贷、经营贷 | 消费意愿 |
| 企业中长期贷款 | 项目、设备投资 | 企业投资意愿 |
| 企业短期贷款、票据融资 | 流动资金 | 票据多时,可能是银行在"冲量",质量不如中长期 |

### 4.1 季节性

放贷有明显的季节规律,比如年初放贷多(常说"开门红")。所以:

- 月度数据**和去年同期比**(同比),不要拿相邻月份硬比
- 看几个月的趋势,不看单月起落

---

## 五、每月数据日历

| 大致时间 | 数据 | 发布方 | 看什么 |
| --- | --- | --- | --- |
| 每月上旬,一般 9 日前后 | CPI、PPI | 国家统计局 | 物价,通胀还是通缩(15 篇) |
| 每月中旬前后 | 金融统计数据:M0、M1、M2,人民币贷款,社融 | 中国人民银行 | 新钱的规模和结构 |
| 每月 20 日左右(遇节假日顺延) | LPR | 全国银行间同业拆借中心 | 贷款利率,尤其是房贷(14 篇) |
| 每个交易日 | 公开市场操作 | 中国人民银行 | 逆回购投放与到期(11 篇) |
| 每季度 | GDP | 国家统计局 | 经济增速和价格(15 篇) |

具体发布日期以国家统计局每年公布的发布日程表、人民银行的公告为准。

---

## 六、一个读数据的顺序

```text
1. 社融增量:比去年同期多还是少
2. 社融结构:是政府债券撑着,还是企业和居民贷款在增长
3. 贷款结构:居民中长期(房贷)、企业中长期(投资)
4. M1 与 M2:钱是在流动,还是在定期账户里躺着
5. 对照 CPI、PPI:新钱有没有推高物价
6. 对照 LPR 和公开市场操作:政策在松还是在紧
```

这样读一遍,就能回答本层开头的问题:新钱是谁借的、借去干什么、有没有真的流动起来。

---

## 常见误区

1. **"只看贷款就够了"**:企业发债、政府债券都不在贷款里,看社融更全
2. **"这个月比上个月少,说明形势变差"**:金融数据季节性强,要看同比
3. **"社融高就说明经济好"**:要看结构,政府债券撑起来的社融不代表企业和居民愿意借钱
4. **"M2 增速高就一定通胀"**:钱可能躺在定期账户里,也可能流进资产,见 15 篇
5. **"M1 可以跨年直接比"**:2025 年起口径变了,先确认口径

## 依据与延伸阅读

- 中国人民银行每月《金融统计数据报告》《社会融资规模增量统计数据报告》
- 中国人民银行关于社会融资规模统计口径调整的说明(政府债券等纳入)
- 国家统计局每年公布的主要统计信息发布日程表
- 全国银行间同业拆借中心 LPR 发布公告
