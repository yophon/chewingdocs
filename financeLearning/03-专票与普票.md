# 专票与普票

02 篇讲了专票为什么能抵扣。这一篇把专票和普票放在一起比:区别在哪、能开给谁、哪些普票其实也能抵扣,以及替公司花钱时该要哪一种。

> 一句话先记住:**专票上的税额,一般纳税人可以拿来抵扣、少交增值税;普票一般不能抵扣。两种都能作为成本入账的凭证。替公司买东西,能开专票就尽量要专票**。

---

## 一、核心区别

| | 增值税专用发票(专票) | 增值税普通发票(普票) |
| --- | --- | --- |
| 能不能抵扣进项 | 能(买方是一般纳税人,且用途允许抵扣) | 一般不能(少数例外见第三节) |
| 能不能作为成本入账 | 能 | 能 |
| 能开给谁 | 单位等经营主体,不能开给个人消费者 | 单位和个人都可以 |
| 票面怎么认 | "电子发票(增值税专用发票)" | "电子发票(普通发票)" |
| 谁能开 | 一般纳税人;小规模纳税人也能开 | 都能开 |
| 买方要提供 | 名称 + 纳税人识别号 | 买方是企业的,同样要提供名称 + 纳税人识别号 |

两种票最根本的区别只有一条:**专票是扣税凭证,普票一般只是记账凭证**。其他差别都从这一条派生出来。比如专票不能开给个人消费者,是因为个人消费者是增值税的最终负担者,没有进项可抵。

---

## 二、用一个例子看差别

公司买了一项服务,含税价 1060 元,税率 6%,票面金额 1000 元、税额 60 元。

| | 开专票 | 开普票 |
| --- | ---: | ---: |
| 公司付出 | 1060 | 1060 |
| 可以抵扣的进项税额 | 60 | 0 |
| **公司实际成本** | **1000** | **1060** |

开普票时,那 60 元税额抵不了,只能和金额一起记成成本。开专票时,60 元可以从公司当期要交的增值税里扣掉,还能顺带少交一点附加税(见 05 篇)。

两个前提:

- **公司是一般纳税人**。如果是小规模纳税人,专票和普票在成本上没有区别(见 02 篇)
- **这笔支出的进项允许抵扣**。餐饮、娱乐、员工福利这类,拿到专票也不能抵(见 06 篇)

---

## 三、能抵扣的普票

有几类票虽然不是专票,一般纳税人也可以按规定抵扣:

### 3.1 高速通行费电子普票

收费公路通行费增值税电子普通发票,可以按发票上注明的增值税额抵扣。

### 3.2 国内旅客运输(出差交通)

2019 年 4 月 1 日起,一般纳税人购进的国内旅客运输服务纳入抵扣范围。可以作为抵扣凭证的包括:

- 注明旅客身份信息的航空运输电子客票行程单,现在是"电子发票(航空运输电子客票行程单)"
- 注明旅客身份信息的铁路车票,现在是"电子发票(铁路电子客票)"
- 注明旅客身份信息的公路、水路等其他客票
- 旅客运输服务的增值税电子普通发票,比如网约车平台开的电子发票

```text
限制条件:
  只限国内旅客运输
  只限本单位员工(签了劳动合同的员工,以及接受的劳务派遣员工)
  具体怎么计算抵扣额,由财务按规定处理
```

出租车的定额发票上没有税额,不能抵扣。

## 四、什么时候要专票

| 场景 | 要什么票 | 原因 |
| --- | --- | --- |
| 替公司采购商品、服务 | 专票 | 进项可以抵扣 |
| 出差住宿 | 专票 | 住宿服务的进项可以抵扣 |
| 出差交通 | 按公司要求开具或下载电子客票发票 | 带身份信息的可以抵扣 |
| 请客户吃饭、娱乐 | 普票即可 | 餐饮、娱乐服务的进项不能抵扣 |
| 员工福利、个人消费 | 普票即可 | 进项不能抵扣 |
| 对方是小规模纳税人 | 能开专票还是要专票 | 能按 1% 或 3% 抵扣,只是抵得少 |

开专票时,把公司全称和纳税人识别号给对方,开出来后核对一遍(见 04 篇)。

---

## 常见误区

1. **"普票不能报销"**——普票可以报销入账,只是不能抵扣
2. **"专票比普票贵"**——同一笔交易,开哪种票卖方要交的税一样多。对方说开专票要"加税点",通常是因为原来的报价本来就没含开票的税
3. **"个人也能要专票"**——专票不能开给个人消费者
4. **"所有普票都不能抵扣"**——通行费电子普票、带旅客身份信息的客票等可以按规定抵扣
5. **"请客吃饭开专票能省税"**——餐饮服务的进项不能抵扣,开专票也没用
