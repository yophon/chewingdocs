# 财税与金融常识总览:从一张发票到一张钞票

这个系列从一个很具体的问题开始:花公司的钱买了一项服务,拿到一张增值税专用发票,这张票有没有报税的时间限制?顺着问下去,会碰到专票和普票的区别、数电票、红字发票、增值税为什么能抵扣;再往下问"增值税只对新增的价值收税,那新增的钞票又是怎么进入市场的",就从财税走到了货币和金融。

> 一句话先记住:**发票是"这笔钱花在哪、税交了多少"的凭证,管的是公司每一笔支出能不能入账、能不能抵税;货币是"大家共同认可的记账",新钱主要由银行贷款创造,决定了市场上有多少钱、利率和物价怎么变。**

---

## 一、两条线怎么接起来

### 1.1 第一条线:发票与增值税

增值税只对每个环节"新增的价值"征税。公司卖东西收到的税叫销项,买东西付出去的税叫进项:

```text
公司要交的增值税 = 销项税额 - 进项税额
```

专票就是"我已经付过这笔进项税"的证明,所以能抵扣。围绕这条公式,会自然引出一串实务问题:

- 公司是一般纳税人还是小规模纳税人?小规模拿到专票也不能抵扣
- 专票和普票有什么区别?什么时候该要专票?
- 抵扣有没有期限?2017 年起开具的专票已经没有期限
- 哪些进项有专票也不能抵?餐饮、娱乐、员工福利
- 开错了怎么办?数电票不能作废,只能开红字发票冲掉

这条线站在员工视角:拿到票知道怎么核对、交给谁、什么时候交。

### 1.2 第二条线:货币与金融

经济在增长,交易在变多,就需要更多的钱来流通。这些钱从哪里来?

```text
印钞厂印钞票 -> 人民银行发行库 -> 商业银行用准备金换现金 -> 你从 ATM 取款
                                                   (只是存款换了形态)

企业或个人贷款 -> 银行在借款人账户里记一笔存款 -> 钱流向供应商、员工、商家
                                                   (这才是新钱)
```

**新钱主要不是印出来的,而是银行放贷时记账记出来的**。人民银行通过降准、降息、向银行投放资金来调节银行的放贷能力,但它不能逼人来借钱。顺着这条线,会引出利率怎么传导、物价怎么衡量、债券为什么跟利率反着走、汇率怎么定、美联储为什么能影响全世界。

### 1.3 两条线的交点

```text
增值税:对"新增的价值"征税       -> 价值是生产出来的
货币:为"新增的价值"提供交易用的钱 -> 钱主要是贷款创造的
```

一个讲公司的钱怎么花得合规、少交冤枉税,一个讲整个经济里的钱从哪里来、值多少。合在一起,就是普通上班族最常碰到的两类"钱的常识"。

## 常见误区

1. **"专票要在 180 天内认证"**:这是旧规则。2017 年 1 月 1 日及以后开具的专票,已经没有认证和抵扣期限
2. **"有专票就能抵扣"**:要看买方是不是一般纳税人,还要看买的是什么,餐饮、娱乐、员工福利的进项不能抵
3. **"印钞机一开,钱就多了"**:印钞票只是把存款换成纸币,新钱主要来自银行贷款
4. **"钱多了物价一定涨"**:钱可能被存起来、流进资产,或者被经济增长消化掉
5. **"银行不会倒"**:存款是银行欠你的钱,银行也会出问题,所以才有存款保险
